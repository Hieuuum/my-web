# hieu.dev

Personal website built with Vite + React + Tailwind CSS.

## Development

```bash
npm install
npm run dev
```

## Adding a blog post

Create `src/posts/your-slug.md`:

```md
---
title: "Title"
date: "YYYY-MM-DD"
excerpt: "One-line summary."
---

Content here.
```

## Stack

- Vite + React
- Tailwind CSS + `@tailwindcss/typography`
- React Router
- Deployed on Vercel
